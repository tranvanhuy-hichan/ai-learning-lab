# Learning

This folder is the "learn" and "note" half of the loop behind this repository. The "apply" half lives in [`projects/`](../projects).

**Learn** → **Note** → **Apply**

| What | Where |
|---|---|
| Where I am and what is next | [ROADMAP.md](ROADMAP.md) |
| Dated entries: what I did, what confused me, what I changed my mind about | [log/](log) |
| One short note per topic, written after I tried it in code | [notes/](notes) |

Every file is bilingual (English first, then Vietnamese).

---

Thư mục này là nửa "học" và "ghi chú" của vòng lặp đằng sau repo. Nửa "áp dụng" nằm trong [`projects/`](../projects).

**Học** → **Ghi chú** → **Áp dụng**

| Nội dung | Vị trí |
|---|---|
| Mình đang ở đâu và bước tiếp theo | [ROADMAP.md](ROADMAP.md) |
| Nhật ký theo ngày: đã làm gì, chỗ nào còn rối, điều gì mình đổi ý | [log/](log) |
| Mỗi chủ đề một ghi chú ngắn, viết sau khi đã thử bằng code | [notes/](notes) |

Mọi file đều song ngữ (tiếng Anh trước, tiếng Việt sau).
